# トレーサビリティ検証

このスキルは、要件・テスト・アーキテクチャ・実装間のトレーサビリティを検証します。

## 検証手順

### 1. 要件 → テスト のトレーサビリティ

`requirement/REQUIREMENTS.md` と `test/TEST_SPEC.md` を読み込み、以下を確認してください：

- 全 FR-xxx に対応する TC-xxx が存在するか
- トレーサビリティマトリクスが最新の要件と一致しているか

### 2. 要件 → アーキテクチャ のトレーサビリティ

`architecture/ARCHITECTURE.md` の「要件トレーサビリティ」セクションを確認し、以下を確認してください：

- 全 FR-xxx が設計上の実現方法と対応付けられているか
- 未対応の FR がないか

### 3. テスト → 実装 のトレーサビリティ

`test/TEST_SPEC.md` と `src/`、`test/` 配下の実装・テストコードを確認し、必要に応じて shared / platform / feature / module 単位の構成も考慮しながら、以下を確認してください：

- 全 TC-xxx に対応するテスト関数が実装されているか
- テストの期待値が仕様書と一致しているか
- 対象プラットフォームに必要なテストが不足していないか
